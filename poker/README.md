# ⚜ Card Games VTT

**EN:** Multiplayer card games for Foundry VTT v13–v14: Poker, Blackjack, Durak and UNO at one table. Out of the box the games use **toy chips** (no character wealth involved — works in any game system); the GM can switch stakes to a character-sheet currency (copper/silver/electrum/gold/platinum, dnd5e-style sheets). UNO ships with the +2/+4 stacking rule always on and **14 optional house rules**. English & Russian UI.

**Install:** Foundry VTT → Add-on Modules → Install Module →
```
https://github.com/BurnSIx-hub/poker-table-vtt/releases/latest/download/module.json
```

## Что это (RU)

Карточные игры для Foundry VTT v13–v14: **Покер · Блэкджек · Дурак · UNO** за одним столом.

Из коробки игры идут на **игрушечные фишки** — деньги персонажей не трогаются, работает в любой системе. В настройках ГМ может включить ставки валютой с листа персонажа: медь / серебро / электрум / золото / платина. В UNO всегда действует стек +2/+4, плюс **14 опциональных хоумрулов**.

## Установка

### Через Foundry (рекомендуется)

**Add-on Modules → Install Module** → вставьте ссылку на манифест (см. выше).

### Вручную

1. Скачайте `module.zip` из [последнего релиза](https://github.com/BurnSIx-hub/poker-table-vtt/releases/latest) и распакуйте в:
   ```
   [Foundry Data]/modules/poker-table-vtt/
   ```
2. В Foundry: **Setup → Add-on Modules → Enable** → включите **Card Games VTT**
3. Войдите в мир и активируйте модуль в настройках мира

Другие модули автора: [BurnSIx-hub/foundry-modules](https://github.com/BurnSIx-hub/foundry-modules)

## Как открыть

| Способ | Кто | Действие |
|---|---|---|
| `Numpad 7` | Только GM | Открыть **лобби у всех** игроков |
| `Shift + <` | Любой | Открыть **своё** лобби |
| Кнопка 🎲 на панели токенов | Любой | Открыть **своё** лобби |

> `<` = клавиша с запятой на русской раскладке (`,`)

## Как использовать

1. GM нажимает `Numpad 7` — лобби открывается у всех активных игроков
2. В лобби выбирается игра (Покер / Блэкджек / Дурак / UNO) и рассаживаются игроки
3. **Начать игру** — раздаются карты
4. Каждый игрок видит **только свои карты**; GM видит все
5. В покере и блэкджеке по умолчанию все получают одинаковый стек **игрушечных фишек** (размер настраивается). Если ГМ включил режим валюты — ставки списываются с листа персонажа и начисляются победителю.

## Настройки (⚙ кнопка внутри стола)

- **Ставки** (GM): «без ставок» (фишки, размер стека) или валюта листа — медь/серебро/электрум/золото/платина. Применяется к новым играм, идущая партия не меняется.
- **Хоумрулы UNO** (GM): 14 переключателей — Jump-in, 7-0 Swap, игра двух карт, принудительная игра, Draw 1, Silent UNO, Kill/Stop, Sudden Death, блеф на +4, Progressive, Empty pile, Double Reverse, лимит руки, выход из игры. Стек +2/+4 включён всегда.
- **Скин карт** — 25 вариантов рубашки. Настраивается **индивидуально** для каждого игрока.
- **Цвет сукна** — 8 пресетов + произвольный цвет. Настраивается **для всего стола** (видят все).

## Валюта и защита

- Режим фишек не трогает лист персонажа вообще — модуль работает в любой системе.
- В режиме валюты модуль читает/пишет `system.currency.<cp|sp|ep|gp|pp>` (dnd5e-совместимые листы).
- Игроки без средств не садятся за стол (покер: меньше большого блайнда — мимо), в минус никто не уходит, банкроты пропускают раунд.

## Архитектура

- **GM** — мастер состояния. Хранит и изменяет объект игры, рассылает `STATE_UPDATE` через `game.socket`
- **Игроки** — получают обновления и отправляют запросы (`REQ_BET`, `REQ_FOLD`, etc.)
- Канал сокета: `module.poker-table-vtt`
